# Nexora Digital Marketing Simulator

An AI-powered digital marketing campaign simulator built with Python.

## 📌 About the Project

Nexora Digital Marketing Simulator helps marketers and businesses simulate a digital marketing campaign before spending real advertising budget.

It estimates campaign funnel performance, calculates important marketing KPIs, compares ad variants, provides optimization recommendations, and supports what-if scenario analysis.

## 🚀 Key Features

- Campaign setup and budget planning
- Target audience selection
- Marketing channel planning
- Budget allocation
- Marketing funnel simulation
- A/B testing
- KPI analysis
- Automated marketing recommendations
- What-if campaign simulation
- Interactive Gradio interface
- Marketing performance dashboard
- Data visualization

## 📊 Marketing KPIs

The simulator calculates:

- CTR – Click Through Rate
- CPC – Cost Per Click
- CPL – Cost Per Lead
- CAC – Customer Acquisition Cost
- ROAS – Return on Ad Spend
